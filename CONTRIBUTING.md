# Contributing

## Getting started

To get started with the `readme-resurrection` project, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/AbbeyIT/readme-resurrection.git
   cd readme-resurrection
   ```

2. Install the project and development dependencies:
   ```sh
   pip install -e ".[dev]"
   ```

## Running tests

To run the tests, use the following command:

```sh
python -m pytest
```

## Where to start

To get started with contributing, you can explore the following entry points and key folders:

- **Entry points**: `resurrect/cli.py`
- **Key folders**: `resurrect/`, `tests/`

## Submitting changes

To submit your changes, follow these steps:

1. Create a new branch:
   ```sh
   git checkout -b your-feature-branch
   ```

2. Make your changes with tests.

3. Run the tests to ensure everything works:
   ```sh
   python -m pytest
   ```

4. Open a pull request on the main repository.
